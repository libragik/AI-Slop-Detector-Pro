## A different style-aware candidate is technically plausible, not validated

Sightengine's [documented `type` model](https://sightengine.com/docs/illustration-photo-detection) returns pixel-based `photo` and `illustration` scores. Illustrations include cartoons, animations and game graphics; photographs can include statues, models and effects. This is appearance classification, **not a distinction between conventionally rendered and generatively produced content**. Its [video API](https://sightengine.com/docs/moderate-stored-video) accepts chosen models. `type` adds one operation per analyzed frame; a combined `genai,type` request therefore reserves six, rather than five. Combined-response alignment and schema still need an actual contract test.

[Gemini video understanding](https://ai.google.dev/gemini-api/docs/video-understanding) can provide a separately prompted visual-style review. Existing local code already requests `content_type`, but that whole-video field does not supply independently verified interval-level style or origin. A new blinded review should receive media and neutral timestamps only, no Sightengine scores, labels, generator names or expected outcomes. Separate providers do not establish statistically independent errors.

One defensible hypothesis is to admit `genai` positives only in intervals where both style reviewers support photographic appearance; illustrative, mixed-style, conflicting or unsupported regions remain **Inconclusive**, including animated AI. A style reviewer must never convert a region into “not AI.” Use interval-level decisions so a CGI host cannot suppress a photographic AI insert. Photorealistic conventional CGI can pass both appearance reviewers and remain a false positive; style disagreement can suppress real detections. This proposal changes scope and selection, not the rejected detector's intrinsic accuracy.

Before any new calls, freeze one style rule, prompt, model identifiers, alignment policy and stage budget. Evaluate photographic real, photoreal AI, photoreal CGI, obvious conventional animation, stylized AI and both styles of mixed insert at all three qualities. Fix human style annotations before model outputs. Require explicit useful coverage, for example at least 90% determined outcomes on the nominated photographic camera/AI subset, alongside per-quality recall and negative false flags; count abstentions as non-detections in unconditional AI recall. Report total and subgroup abstention, false positives, conditional and unconditional recall, and uncertainty grouped by source ancestry. Improvements obtained solely by declining most cases do not pass.
