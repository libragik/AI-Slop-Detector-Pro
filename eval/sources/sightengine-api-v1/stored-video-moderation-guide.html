                                          Stored Video Analysis

                                          Approaches

                                          There are two ways to analyze a Stored Video — whether you want to moderate content, detect AI-generated videos, spot deepfakes or run any other model. You can choose between synchronous processing, where the analysis happens during your API request, or asynchronous processing. While both yield the same results, they differ in their implementations. Synchronous processing is quicker to setup, but will only work for short videos (up to 60s).

                                          GUIDE

                                          Short Video Analysis (sync)

                                          Analyze short videos (up to 60s) with a simple mechanism. Everything happens within a single API request cycle.
                                          GUIDE

                                          Video Analysis (async)

                                          Analyze stored videos of any length and any type. The job happens outside of the API request cycle. Results are sent back through callbacks.
