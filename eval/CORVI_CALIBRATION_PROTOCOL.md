# Corvi calibration protocol — not run

**Stopped before threshold fitting or calibration.** The development screen found severe-transformation AUROC 0.6558 on 23 AI and twelve real source clips. This loss of ranking after processing is the strongest basis for stopping. Every CGI control also scored above every mixed control: CGI means −5.557, −6.651, −0.703; mixed means −11.958, −11.940, −10.998. A single monotonic threshold cannot separate these recorded pipeline outputs, but this is not an isolated test of recognizing inserted generated pixels: the eight-frame sampler saw zero inserted-source frames in the 0.5-second and one-second controls, and two in the two-second control. The inserted parent has a dataset-author whole-video label, without a generation receipt or per-frame origin record. The controls cover two underlying scenarios. See the [sampling/provenance qualification](./MIXED_CONTROL_PROVENANCE.md) and `sources/corvi-social-screen-summary.json`. No additional 250-derivative run, threshold fit, calibration read, or consumed-holdout scoring was performed for this protocol.

The prospective plan below documents the gate that would have applied had the development representation survived. It is not authorization to continue this rejected candidate.

1. Keep the model, native-frame preprocessing, eight-frame sampling and mean raw-score aggregation fixed. Use the 125 development originals and their 250 registered derivatives: 61 AI and 64 real source groups. Never use transformation names as model features or change thresholds by known transformation label.
2. Use five deterministic, label-stratified folds grouped by original source. Keep all three versions together. Within each training fold, compute each real group's maximum score across its variants. Select one threshold using only those training-negative maxima, allowing at most `floor(0.05 × training real groups)` flagged groups under the strict rule `score > threshold`. Ties remain negative. Evaluate on the excluded groups; do not select model settings from these folds.
3. Require pooled out-of-fold AI recall of at least **70% in each quality category**, and at most **5% observed real source groups with any variant falsely flagged**. Report per-quality recall/FPR, source-group uncertainty, all scan errors and abstentions. AI errors/abstentions count as recall misses; unresolved errors prevent advancement rather than disappearing from denominators. Report both observed false flags and an error-inclusive conservative bound for real groups.
4. Only if those gates pass, fit the same single threshold rule on all 64 development real-group maxima; this permits at most three falsely flagged groups. Require zero positive decisions on the separate CGI controls. Do not move the threshold to repair a failed CGI gate or add quality-specific rules.
5. Freeze threshold, source hashes, preprocessing and scoring before reading the untouched 30-clip calibration set. Treat that set as a prospective confirmation check, not another fitting opportunity. Report its small denominators and uncertainty; failure stops the candidate. Never score or tune against the already consumed 75-clip holdout for a new accuracy claim.

The observed 5% target would not establish a 5% population error bound. Additional files selected from the same public archive would be file-disjoint only; they would not establish independent camera/generator origin. A future representation needs a new preregistered study and independent-origin evidence, not further Corvi threshold variants.
