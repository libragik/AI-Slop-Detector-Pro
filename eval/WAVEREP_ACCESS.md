# WaveRep video-detector access check

The official NeurIPS2025 WaveRep release is a distinct, video-trained candidate from the older CORVI2023 image detector evaluated here. Its downloadable DINOv2 weights are reachable, so lack of NVIDIA NIM hardware is not sufficient reason to rule out this research release. The project's informational/nonprofit use restriction still needs to match the intended project scope; the user has been asked whether this detector is personal/noncommercial or commercial. No model weights were downloaded or run.

Official revision: [0fd6010759c14b572b7842a28fa9f85fe1ddd2fd](https://github.com/grip-unina/WaveRep-SyntheticVideoDetection/tree/0fd6010759c14b572b7842a28fa9f85fe1ddd2fd). NVIDIA's [research page](https://research.nvidia.com/labs/amri/publication/corvi2025svd/) links this implementation. Its published wavelet-based training augmentation targets low-level generation traces rather than semantic implausibility. It is not the same released ensemble as NVIDIA's current gated NIM service.

## Concrete availability

- The [demo README](https://github.com/grip-unina/WaveRep-SyntheticVideoDetection/blob/0fd6010759c14b572b7842a28fa9f85fe1ddd2fd/demo/README.md) links G1 and G4 DINOv2 checkpoints and supplies MD5 checksums. Anonymous HEAD of the official G4 URL returned HTTP200 with Content-Length346163178. No body or complete-download hash was acquired.
- The [demo license](https://github.com/grip-unina/WaveRep-SyntheticVideoDetection/blob/0fd6010759c14b572b7842a28fa9f85fe1ddd2fd/demo/LICENSE.md) and root license restrict use to informational/nonprofit purposes and prohibit unauthorized industrial/profit-oriented use. This differs from an unrestricted MIT/Apache integration path. The actual project purpose remains user input; do not assume a commercial prohibition applies to a purely personal nonprofit experiment.
- The [inference entry point](https://github.com/grip-unina/WaveRep-SyntheticVideoDetection/blob/0fd6010759c14b572b7842a28fa9f85fe1ddd2fd/demo/main_avideo.py) accepts a device argument. It defaults to CUDA, but the inspected PyTorch/timm path has no demonstrated CUDA-only custom operator. CPU/MPS feasibility remains unmeasured.
- Architecture is timm vit_base_patch14_reg4_dinov2.lvd142m with a one-output head,504-pixel center crop,ImageNet normalization and RGB conversion. The official default visits every decoded video frame and averages logits; positive mean logits indicate synthetic. An eight-frame shortcut would change that protocol and must not silently be substituted.
- The [loader](https://github.com/grip-unina/WaveRep-SyntheticVideoDetection/blob/0fd6010759c14b572b7842a28fa9f85fe1ddd2fd/demo/utils.py) uses pretrained=True and an unqualified torch.load. Any authorized local experiment must inspect a weights-only load,verify complete state-dict coverage,use pinned source and avoid an unnecessary pretrained network fetch; no unsafe loader execution has occurred.
